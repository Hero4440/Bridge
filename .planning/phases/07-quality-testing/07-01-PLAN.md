    3. **Problem (15 seconds):**
       - "The gap isn't knowing what to say - it's showing up"

       - Show signup (or use pre-created account)
       - "5-step onboarding: interests, meet Mo, trusted person, comfort settings"
       - Fast-forward or skip if time-constrained
    5. **Practice Feature (2 minutes) - THE STAR:**
       - "The core feature is Practice"
       - "Users practice conversations with AI feedback BEFORE real situations"
       - Open Practice → Pick "Join a Chat"
       - "Level 1 - Guided support. User sets their OWN goal"
       - Type goal: "I want to sound friendly"
       - Type message: "Hey everyone! Mind if I join?"
       - "Mo is thinking... this is real Bedrock Claude, not hardcoded"
       - **Show AI response:**
         - "Mo plays the partner: [read partnerReply]"
         - "Strength: [read strength] - genuine, specific"
         - "Tip: [read tip] - actionable, tied to their goal"
       - "This is THE differentiator - personalized AI feedback"
       - "7 scenarios, 3 difficulty levels, fading support"
    6. **Social Features (45 seconds):**
       - "After practice, users try it for real"
       - Circles: "Interest groups with live chat"
       - Events: "Preview what to expect, RSVP, get prep checklists"
       - DMs: "Message requests with safety checks"
    7. **Safety (15 seconds):**
       - "Safety from day one"
       - "Crisis detection - if someone types about self-harm, they see 988 immediately"
       - "No raw transcripts stored, privacy-first"
    8. **Impact (15 seconds):**
       - "Research shows conversation practice has strong effect sizes"
       - "But real get-togethers need support systems like Bridge"
       - "Practice → Preview → Go - building confidence at their pace"
    9. **Closing (15 seconds):**
       - "Questions?"
       - OR "Thank you!"
    10. Add **timing marks** at each section
    11. Add **backup plan** section:
        - If Bedrock slow: "Sometimes takes 5 seconds, let me show another feature"
        - If Bedrock fails: "Fallback response kicks in, but let me show the social features"
        - If app crashes: "Let me show you the architecture instead" (have diagrams ready)
