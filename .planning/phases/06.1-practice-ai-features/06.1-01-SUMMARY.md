## Technical Details

**Files created:** 2  
**Files modified:** 3  
**Lines of code:** ~650

**API Integration:**
```typescript
const result = await practiceTurn(scenarioId, level, goal, message);
// Returns: { partnerReply, strength, tip, fallback, crisis }
```

**Data flow:**
1. User picks scenario → stores scenarioId
2. User sets level (1-3) + goal → advances to conversation
3. User types message → calls practiceTurn() → Bedrock generates feedback
4. If crisis: true → 988 alert, reset to picker
5. If success → show partnerReply, strength, tip
6. Try Again → clear message, stay in conversation
7. Done → reset everything, return to picker

**Crisis handling:**
- Detects via Lambda's `classify()` function
- Shows 988 Suicide & Crisis Lifeline alert
- Mentions Crisis Text Line (741741)
- Immediately resets to scenario picker

**No persistence:**
- PracticeRun model exists but not used (CONTEXT decision)
- User can practice multiple times but no history saved
- Focus on live demo, not tracking
